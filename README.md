# TravelEase — Simple Travel Website (Beginner Mini Project)

A 6-page travel website built with beginner-friendly HTML, CSS, and a little JavaScript.
No frameworks, no build tools — just open `index.html` in a browser.

## Pages
- `index.html` — Home page (hero, popular destinations, why choose us, testimonials)
- `destinations.html` — Destination cards with category filter buttons
- `packages.html` — Pricing cards (Basic / Standard / Premium)
- `gallery.html` — Simple photo grid
- `about.html` — Company story + team
- `contact.html` — Contact form + Google Map

## What's used (easy to explain in viva)
- Flexbox → navbar, footer links
- CSS Grid → destination cards, pricing cards, gallery
- Media query (`@media`) → mobile hamburger menu
- Basic JavaScript → toggle menu, filter buttons, form submit alert
- HTML5 form validation → `required`, `type="email"`

## Notes
- Images use `picsum.photos` as free placeholder images (needs internet to load).
  Replace with your own images in an `images/` folder before final submission if you want.
- To run: just double-click `index.html`, or open it in your browser.
